## Tema 2

Azure es un conjunto de centros de datos.

Si los clientes son europeos, los datos tienen que estar en Europa.

Cada región tiene zonas de disponibilidad formadas por diferentes data centers. Los datos entre regiones no pagan.

Regiones pares: son para hacer contingencias y replicar datos con menos latencia y menos costes. El lugar de preferencia para replicar tu sistema.

Regiones soberanas: gobiernos
	- Azure China funciona diferente con administración propia

### Gobernanza y cumplimiento

Se bloquean recursos con políticas (Azure Policy)

Es diferente un permiso que una política.
- El permiso te permite hacer
- La política restringe los permisos. Se hace antes de crear el recurso para ver si está permitido.

#### Bloqueos de recursos

El bloqueo de Eliminar impide que puedas eliminar el recurso.
Los bloqueos son para los atributos, se pueden hacer las operaciones dentro del recurso, pero no eliminarlo o modificarlo, por ejemplo.

No se cambian permisos de aplicación, sino de recursos de Azure.
