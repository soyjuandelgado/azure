## 3. Module 02: Deploy a container to Azure App Service

|   |
|---|
|**Introduction:**|
|In this exercise, you deploy a Linux container image from Azure Container Registry (ACR) to Azure App Service. You configure the web app to use a system-assigned managed identity and the **AcrPull** role so App Service can pull images from your private registry without storing registry credentials in app settings.|
|Tasks performed in this exercise:<br><br>- Download the project starter files<br>- Deploy Azure Container Registry and build a container image using ACR Tasks<br>- Deploy an App Service plan for Linux containers<br>- Create and configure a Web App for Containers to pull from ACR using managed identity<br>- Configure runtime settings and enable container logging<br>- Verify the deployment and test the document processing endpoint|
|This exercise takes approximately **30** minutes to complete.|
## 4. Module 02: Deploy a container to Azure App Service

|   |
|---|
|**Task 1:** Download project starter files and deploy Azure services|
|In this section you download the project starter files and use a script to deploy the necessary services to your Azure subscription. The Azure Container Registry and App Service plan deployment takes a few minutes to complete.|
|1. Open **Edge** browser from the taskbar, and enter the following URL to download the starter file. The file will be saved in your default download location.<br><br>```<br>https://github.com/MicrosoftLearning/mslearn-azure-ai/raw/main/downloads/python/app-svc-container-python.zip<br>```|
|2. Open **File Explorer** from the taskbar, right click on the downloaded file then select **Extract all..** and then click **Extract**.|
|3. Launch **Visual Studio Code (VS Code)** from the **Desktop** and select **File > Open Folder...** in the menu, select **Downloads** folder then choose the folder containing the project files and then click **Select folder**.<br><br>📝 **Note:** If prompted, select **Yes, i trust the authors**.|
|4. The project contains a deployment script, click on the python script (_azdeploy.py_). Change the two values at the top of the script to meet your needs, then save your changes.<br><br>📝 **Note:** Do not change anything else in the script.<br><br>```<br>"<your-resource-group-name>" # Resource Group name<br>"<your-azure-region>" # Azure region for the resources, enter East US<br>```<br><br>📝 **Note:** For the Azure region, enter **`canadacentral`**.|
|5. In the **`azdeploy.py`** scroll down to **line no 224** and then change the **`sku`** value to **`B1`**.|
|6. Click **File** and then click **Save**.|
|7. In the menu bar select **Terminal > New Terminal** to open a terminal window in VS Code.<br><br>💡 **Tip:** If **Terminal** tab is not visible, select the three dots (**...** > **Terminal** > **New Terminal**)|
|8. Run the following command to login to your Azure account. Answer the prompts to select your Azure account and subscription for the exercise.<br><br>```<br>az login<br>```|
|9. When prompted, select **Work or school account**, click **Continue** and then follow the instructions to sign into Azure using the credentials from the lab **Info** tab. When prompted to **Sign in to all apps..**, select **No, this app only**.<br><br>📝 **Note:** If you do not see the **Sign in** window, minimize the **Visual Studio Code** to see it.|
|10. When prompted in the terminal to **Select a subscription**, press **Enter**.|
|11. Run the following commands to ensure your subscription has the necessary resource providers for Azure Container Registry (ACR) and Azure App Service.<br><br>```<br>az provider register --namespace Microsoft.ContainerRegistry<br>az provider register --namespace Microsoft.Web<br>```|
|12. Make sure you are in the root directory of the project and run the following command in the terminal to launch the deployment script. The deployment script deploys ACR and creates the environment variable files needed for the exercise.<br><br>```powershell<br>python azdeploy.py<br>```|
|13. When the script is running, enter **1** to launch the **1. Create Azure Container Registry and build container image** option. This option creates the ACR service and uses ACR Tasks to build and push the image to the registry.|
|14. When the previous operation is finished, enter **2** to launch the **Create App Service Plan** option. This option creates the App Service plan needed for the web app.<br><br>📝 **Note:** A file containing environment variables is created after the App Service plan is created. You use these variables throughout the exercise.|
|15. When the previous operation is finished, enter **4** to exit the deployment script.|
|16. Run the appropriate command to load the environment variables into your terminal session from the file created in the previous step.<br><br>```powershell<br>. .\.env.ps1<br>```<br><br>📝 **Note:** Keep the terminal open. If you close it and create a new terminal, you might need to run the command to create the environment variable again.|
