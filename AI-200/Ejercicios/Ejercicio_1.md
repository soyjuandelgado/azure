## 5. Module 01: Build and run a container image with ACR Tasks

|                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Task 2:** Build the image with ACR Tasks                                                                                                                                                                                                                                                                                                              |
| In this section you use a quick task to build the image in Azure without requiring Docker on your local machine. The **az acr build** command uploads your source files, builds the image in the cloud, and pushes it to your registry.                                                                                                                 |
| 1. Run the following command to build, and push it to your registry. The build completes entirely in Azure. No local Docker installation is required.<br><br>```powershell<br>az acr build `<br>    --registry $env:ACR_NAME `<br>    --image inference-api:v1.0.0 `<br>    ./api<br>```<br><br>📝 **Note:** Ignore any warnings or notices if appears. |
| 2. Watch the output as ACR Tasks:<br><br>- Packs and uploads your source context to Azure<br>- Queues and starts the build task<br>- Streams the Docker build output showing each layer<br>- Pushes the completed image to your registry<br>- Reports the image digest and task status                                                                  |
## 6. Module 01: Build and run a container image with ACR Tasks

|                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Task 3:** Verify the image in the registry                                                                                                                                                                                                                                                                                                                   |
| In this section you confirm the image exists in your registry by listing repositories and tags.                                                                                                                                                                                                                                                                |
| 1. Run the following command to list all repositories in the registry.<br><br>```powershell<br>az acr repository list --name $env:ACR_NAME --output table<br>```<br><br>📝 **Note:** The output shows the **inference-api** repository you created.                                                                                                            |
| 2. Run the following command to list tags for the **inference-api** repository.<br><br>```powershell<br>az acr repository show-tags `<br>    --name $env:ACR_NAME `<br>    --repository inference-api `<br>    --output table<br>```<br><br>📝 **Note:** The output shows the **v1.0.0** tag you assigned during the build.                                    |
| 3. Run the following command to view detailed manifest information, including the digest.<br><br>```powershell<br>az acr manifest list-metadata `<br>    --registry $env:ACR_NAME `<br>    --name inference-api `<br>    --output table<br>```<br><br>📝 **Note:** Note the digest value. This SHA-256 hash uniquely identifies your image regardless of tags. |
## 7. Module 01: Build and run a container image with ACR Tasks

|   |
|---|
|**Task 4:** Run the image with ACR Tasks|
|In this section you use the **az acr run** command to execute a command inside your built image and verify it works correctly.|
|1. Run the following command to verify the Flask application loads correctly in the container.<br><br>```powershell<br>az acr run `<br>    --registry $env:ACR_NAME `<br>    --cmd "$env:ACR_NAME.azurecr.io/inference-api:v1.0.0 python -c 'from app import app'" `<br>    /dev/null<br>```<br><br>📝 **Note:** The output includes Docker pull progress as it downloads the image. A successful run ends with **Run ID: xxx was successful after xxx**. This confirms the container runs correctly and the Flask application imports without errors.|

|                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Task 6:** View build history and lock a production image                                                                                                                                                                                                                                                                                                                            |
| In this section you review the ACR task run history and lock an image to protect it from accidental changes.                                                                                                                                                                                                                                                                          |
| 1. Run the following command to review the ACR task run history to see all builds you've performed.<br><br>```powershell<br>az acr task list-runs `<br>    --registry $env:ACR_NAME `<br>    --output table<br>```<br><br>📝 **Note:** The output shows each build task with its run ID, status, trigger type, and duration. This history helps you track builds and diagnose issues. |
| 2. Run the following command to lock your v1.0.0 image to prevent accidental deletion or modification.<br><br>```powershell<br>az acr repository update `<br>    --name $env:ACR_NAME `<br>    --image inference-api:v1.0.0 `<br>    --write-enabled false<br>```                                                                                                                     |
| 3. Run the following command to verify the lock is in place.<br><br>```powershell<br>az acr repository show `<br>    --name $env:ACR_NAME `<br>    --image inference-api:v1.0.0<br>```<br><br>📝 **Note:** The **writeEnabled** field shows **False**, indicating the image is protected.                                                                                             |
