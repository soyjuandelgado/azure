## Tema 2

Azure es un conjunto de centros de datos.

Si los clientes son europeos, los datos tienen que estar en Europa.

Cada región tiene zonas de disponibilidad formadas por diferentes data centers. Los datos entre regiones no pagan.

Regiones pares: son para hacer contingencias y replicar datos con menos latencia y menos costes. El lugar de preferencia para replicar tu sistema.

Regiones soberanas: gobiernos
	- Azure China funciona diferente con administración propia

#### Suscripciones de Azure

Una cuenta puede tener múltiples suscripciones.
A partir de 3000€/mes puedes tener cuenta con agente que da soporte.

Las suscripciones de pruebas y de desarrollo son más económicas que las de producción.

Si creas un producto SaaS para tus clientes, éste se tiene que alojar en producción.
